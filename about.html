Hey! I'm Sudeepa Wanigarathna (aka CerberusMrXi). I am the CEO & Founder of Serendibware, a security researcher, exploit developer, and Software Engineering & Cybersecurity undergraduate at NIBM Sri Lanka.


I direct operations at Serendibware while contributing to public offensive security research, disclosing vulnerability PoCs, and designing modular security frameworks (such as Cerberus Blue).


"Understanding the exploit is the key to building the defense."

My path in offensive security is driven by low-level code review and exploit automation. I research newly disclosed CVEs and create public exploit PoCs to assist defense teams. Some of my notable exploit research includes:

  • CVE-2025-55182: Next.js / React Server Components RCE Scanner (React2Shell).
  • CVE-2026-48909: Joomla SP LMS SP Object Injection leading to RCE.
  • CVE-2023-44487: HTTP/2 Rapid Reset PoC Exploit.
  • CVE-2026-33017: Langflow Code Injection RCE tool.
  • CVE-2026-23744: MCPJam Inspector RCE.

All research, code PoCs, and toolsets shared on my GitHub and this blog are meant strictly for educational analysis, authorized red team assessments, and remediation planning.
